# 詳解撰寫規範

新增試卷時，`tools/import_exam.py import` 會產生待補清單 `exam_work/<年度>/todo.json`。照本規範替每題補上標籤、考點與詳解，存成 `exam_work/<年度>/done*.json`（可分多個檔案），再執行 `tools/import_exam.py apply <年度>`。

## 輸出格式

JSON 物件，以題目 id（字串）為鍵：

```json
{
  "2182": {
    "tags": ["法規倫理", "護理通論"],
    "topics": { "法規倫理": "NP法規/業務範圍", "護理通論": "NP角色定位" },
    "explanation": "### 【核心考點】\n..."
  }
}
```

- `answer` 是衛福部官方答案，**不可更改**；詳解必須支持官方答案。
- 有 `image_file` 的題目要先看圖。選項寫「見圖（A）」表示選項本身就是圖。
- 內外科共同題在清單中只出現一次，`apply` 會自動套用到另一科。

## tags

1–5 個，只能從下列 18 個選，最相關的放第一個：

消化系統、藥理用藥、呼吸系統、心臟血管、神經系統、評估診斷、血液腫瘤、感染免疫、外科周手術、內分泌代謝、護理通論、骨骼肌肉、腎臟泌尿、重症加護、法規倫理、婦產科、精神科、兒科

法規、專師業務範圍的題目用「法規倫理」，角色、溝通、教學相關再加「護理通論」。

## topics

每個用到的 tag 都要指定一個子考點，名稱必須與 `data/topics.json` 中該科別下的鍵完全相同。

## explanation

繁體中文，醫學術語保留英文，每題約 150–300 字，結構固定：

```
### 【核心考點】
一句話考點

### 【解析推理】
2–5 句推理，引用現行 guideline 或法規（例如 2023 ESC、KDIGO、Surviving Sepsis Campaign 2021、
專科護理師於醫師監督下執行醫療業務辦法）

### 【選項分析】
(A) → ✅ 理由
(B) → ❌ 理由
(C) → ❌ 理由
(D) → ❌ 理由

### 【高頻連結】
- 2–3 個相關高頻考點

### 【記憶筆記】
- 1–3 個口訣，陷阱用 ⚠️ 標示
```

- ✅ **只標在官方答案的選項**；「何者錯誤／最不適當」這類題目也一樣，✅ 標在該選的那個錯誤敘述上。送分題四個選項都標 ✅。
- 選項分析一定要是 (A)–(D) 四行，組合題（①②③④）也一樣，每行說明該組合為何對錯。選項分析中不要使用 ⚠️。
- 若認為官方答案有爭議，仍照官方答案解說，另加一行「⚠️ 本題官方答案為 X，…」說明。
