# 專科護理師冒險記 ⚔️（NP Quest）

台灣專科護理師（NP）國家考試刷題系統。像素 RPG 風格、單一 HTML 檔、零後端，直接用瀏覽器開啟即可使用。

| 項目 | 內容 |
|---|---|
| 題庫 | 109–114 年度歷屆試題，共 1,918 筆（含 21 筆考卷說明列，實際考題 1,897 題） |
| 考試類型 | 通論、進階內科、進階外科 |
| 科別 | 18 個細科，分 4 大類（內科系／外科系／專科／基礎通論） |
| 詳解 | 1,918 筆預先生成的 Markdown 詳解（內嵌） |
| 考點分析 | 18 科 × 379 個考點主題，含星等、題目對應、主題講義 |
| 技術 | Vanilla JS（無框架、無建置）、Chart.js 4.4.0、marked 15.0.7 |
| 儲存 | 全部存在瀏覽器 `localStorage`，無伺服器、無帳號 |

## 快速開始

```bash
# 方法 1：直接開檔（file:// 即可運作，題庫已內嵌）
open index.html

# 方法 2：本機靜態伺服器
python3 -m http.server 8000   # 開 http://localhost:8000
```

部署：把 `index.html` 放到任何靜態主機（GitHub Pages、Netlify、S3…）即可，沒有建置步驟。

## 功能一覽

- **刷題系統**：混合／年份／科別／錯題／智慧複習（SRS）五種模式；每題 60 秒計時；即時或延後詳解
- **重點考點**：依考點出題次數給星等（★1–★5），展開可看主題講義與「練習這個考點」
- **成績與分析**：本次分數、等級、科別雷達圖、累計弱點科別、近 10 次正確率趨勢
- **個人化講義**：錯題整理，可列印／存 PDF
- **筆記本**：每題 Markdown 筆記，支援搜尋、排序、JSON 匯出／匯入
- **成就系統**、**7 種主題配色**、**未完成練習自動續做**
